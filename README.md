# Sistema de Reservas de Canchas Deportivas

Aplicación web que permite a los usuarios reservar canchas deportivas de forma rápida y sencilla, evitando reservas duplicadas mediante almacenamiento local.

## Funcionalidades principales

- Crear una nueva reserva indicando nombre, tipo de cancha, fecha y hora.
- Mostrar la lista de reservas existentes.
- Cancelar una reserva ya creada.
- Validar y evitar reservas duplicadas para la misma cancha, fecha y hora.
- Persistencia de datos en el navegador usando `localStorage`.
